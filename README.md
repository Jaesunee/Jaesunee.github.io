# jasonchung.me

Personal portfolio — React 18 + Vite + Tailwind CSS + Motion, deployed to GitHub Pages (`gh-pages` branch) by `.github/workflows/pages.yml`.

```sh
npm install
npm run dev      # local dev server
npm run build    # production build → ./build
```

Content lives in `src/data.js`. Light/dark mode is toggled from the navbar.
